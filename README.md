# Eclipse
Eclipse is an alternative keyboard layout designed for standard row-staggered keyboards.

The main benefit of Eclipse is the extremely low SFB percentage, especially on the left pinky and ring fingers: BNZ and FSX columns roughly amount to a combined total of only 0.02% SFB and 0.26% SFS. 

Left middle finger features the keys RLH in a triangular cluster rather than a straight column. This is notable because R is a particularly hard letter to pair with other letters SFB wise, so placing it on a strong and flexible middle finger allows you to alt-finger certain bigrams like RL and HR in order to achieve even lower SFB percentage. The triangular cluster shape also promotes less movement as a result of all 3 keys being adjacent to one another.
